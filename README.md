# TradeHighlight

Client-side Fabric mod for Minecraft 1.21.11. In the villager trading screen it draws a border around the best trades and plays a sound when one shows up.

- **Gold**: enchanted books with the enchantments you selected (default: Mending)
- **Green**: books with a maxed-out enchantment (optional)

Choose your enchantments in **Mod Menu** (Mods -> TradeHighlight -> config button), or edit `config/tradehighlight.json`.
Nothing is sent to the server, so it works on any server.
